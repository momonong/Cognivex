## 🔄 後端處理流程

### 完整的數據流

```
使用者點擊 "Start Analysis"
         │
         ▼
┌────────────────────────────────────────┐
│ 1. 收集輸入參數                        │
│    - subject_id: "sub-ADNI002S0295"   │
│    - mri_path: "path/to/t1.nii.gz"    │
│    - analysis_mode: "structural"      │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 2. LangGraph Workflow 啟動             │
│    app.invoke(initial_state)          │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 3. Router 節點                         │
│    route_by_analysis_mode()           │
│    → 返回 "structural_mri_inference"  │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 4. Structural MRI Inference Agent      │
│    ┌────────────────────────────────┐ │
│    │ 4.1 載入模型                   │ │
│    │     MLModelLoader.get_all()    │ │
│    │     ✓ Random Forest            │ │
│    │     ✓ Scaler                   │ │
│    │     ✓ ROI List                 │ │
│    ├────────────────────────────────┤ │
│    │ 4.2 提取特徵                   │ │
│    │     ROIFeatureExtractor        │ │
│    │     ✓ Load AAL Atlas           │ │
│    │     ✓ Extract 32 ROIs          │ │
│    │     ✓ Calculate mean intensity │ │
│    ├────────────────────────────────┤ │
│    │ 4.3 標準化                     │ │
│    │     scaler.transform()         │ │
│    ├────────────────────────────────┤ │
│    │ 4.4 預測                       │ │
│    │     model.predict()            │ │
│    │     model.predict_proba()      │ │
│    │     ✓ Classification: AD       │ │
│    │     ✓ Confidence: 78.5%        │ │
│    ├────────────────────────────────┤ │
│    │ 4.5 特徵重要性                 │ │
│    │     model.feature_importances_ │ │
│    └────────────────────────────────┘ │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 5. Feature Analyzer Agent              │
│    ┌────────────────────────────────┐ │
│    │ 5.1 排序特徵                   │ │
│    │     sorted(importances)        │ │
│    ├────────────────────────────────┤ │
│    │ 5.2 選擇 Top 10                │ │
│    ├────────────────────────────────┤ │
│    │ 5.3 轉換格式                   │ │
│    │     → BrainRegionInfo          │ │
│    ├────────────────────────────────┤ │
│    │ 5.4 設定排名                   │ │
│    │     importance_rank: 1-32      │ │
│    └────────────────────────────────┘ │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 6. Visualizer Agent                    │
│    ┌────────────────────────────────┐ │
│    │ 6.1 特徵重要性圖表             │ │
│    │     plot_feature_importance()  │ │
│    │     → PNG 檔案                 │ │
│    ├────────────────────────────────┤ │
│    │ 6.2 3D 腦區視覺化              │ │
│    │     plot_roi_on_brain()        │ │
│    │     → PNG 檔案                 │ │
│    └────────────────────────────────┘ │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 7. Entity Linker (共用)                │
│    link_entities()                     │
│    → 標準化 ROI 名稱                   │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 8. Knowledge Reasoner (共用)           │
│    enrich_with_knowledge_graph()       │
│    → 查詢臨床意義                      │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 9. Image Explainer (共用)              │
│    explain_image()                     │
│    → 視覺分析                          │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 10. Report Generator (擴展)            │
│     generate_structural_report()       │
│     ┌────────────────────────────────┐│
│     │ 10.1 收集資訊                  ││
│     │      - 分類結果                ││
│     │      - 信心分數                ││
│     │      - Top 10 ROI              ││
│     ├────────────────────────────────┤│
│     │ 10.2 生成英文報告              ││
│     │      llm_response()            ││
│     ├────────────────────────────────┤│
│     │ 10.3 翻譯中文                  ││
│     │      llm_response()            ││
│     └────────────────────────────────┘│
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 11. 返回最終狀態                       │
│     final_state = {                    │
│       classification_result: "AD",     │
│       prediction_confidence: 0.785,    │
│       roi_features: {...},             │
│       feature_importances: {...},      │
│       activated_regions: [...],        │
│       visualization_paths: [...],      │
│       generated_reports: {...}         │
│     }                                  │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│ 12. UI 顯示結果                        │
│     render_structural_results()        │
└────────────────────────────────────────┘
```
