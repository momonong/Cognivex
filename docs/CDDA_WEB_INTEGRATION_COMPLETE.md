## 🎯 功能特色

### CDDA Framework 整合

#### 1. 雙框架支援
```python
# 使用者可選擇：
- CDDA Framework (推薦) ✨
  - 自主決策代理
  - 反事實分析
  - 異常檢測
  - 混合病理識別
  
- 傳統 LangGraph
  - 標準分析管線
  - 腦激活圖
  - 雙語報告
```

#### 2. LLM 模式切換
```python
# 規則式模式（預設）
use_llm = False
- 快速執行（~10-30 秒）
- 不需要 GPU
- 穩定可靠

# LLM 模式
use_llm = True
- 豐富的臨床推理
- 自然語言解釋
- 需要 GPU（~2-5 分鐘）
```

#### 3. 完整推理鏈
```python
# 顯示內容：
- Agent A 編排過程
- MCP 操作記錄（含時間戳記）
- A2A 交接詳情
- Agent B 合成過程
- 決策理由
```

#### 4. 互動式結果展示
```python
# 診斷摘要
- 受試者 ID
- 預測結果（AD/NC）
- 信心度
- UQ 評分
- 代理決策類型

# 反事實分析（如觸發）
- 原始 vs 模擬預測
- 信心度變化
- 特徵影響解釋

# 異常區域（如觸發）
- 異常腦區列表
- Z-score 評分
- 臨床意義
```

## 🏗️ 架構設計

### 應用結構

```
app_cdda.py
├── 工具函數
│   ├── load_nifti()           # NIfTI 檔案載入（快取）
│   ├── initialize_cdda_agent() # CDDA Agent 初始化（快取）
│   ├── format_cdda_report()   # 報告格式化
│   └── display_reasoning_chain() # 推理鏈顯示
│
├── Streamlit 主體
│   ├── 頁面配置
│   ├── 側邊欄控制
│   │   ├── 框架選擇
│   │   ├── 受試者選擇
│   │   ├── CDDA 設定
│   │   └── 控制按鈕
│   │
│   ├── 分析邏輯
│   │   ├── CDDA 分析流程
│   │   └── LangGraph 分析流程
│   │
│   └── 結果顯示
│       ├── CDDA 結果
│       ├── LangGraph 結果
│       └── 互動式檢視器
│
└── 頁尾資訊
```

### 資料流

```
使用者輸入
    ↓
選擇框架（CDDA / LangGraph）
    ↓
選擇受試者
    ↓
配置設定（LLM 模式、推理鏈）
    ↓
開始分析
    ↓
    ├─ CDDA 路徑
    │   ├─ 初始化 CDDA Agent
    │   ├─ 執行 run_analysis()
    │   ├─ 獲取 AgentResult
    │   └─ 格式化報告
    │
    └─ LangGraph 路徑
        ├─ 準備初始狀態
        ├─ 執行 workflow
        ├─ 獲取 final_state
        └─ 顯示結果
    ↓
顯示結果
    ├─ 診斷摘要
    ├─ 預測驗證
    ├─ 推理鏈（可選）
    ├─ 元數據（可選）
    └─ 互動式檢視器
```

## 🚀 使用方式

### 快速開始

#### 方法 1: 啟動腳本（推薦）
```bash
run_cdda_app.bat
```

#### 方法 2: 命令列
```bash
streamlit run app_cdda.py
```

#### 方法 3: 指定埠號
```bash
streamlit run app_cdda.py --server.port 8502
```

### 基本流程

1. **啟動應用** → 瀏覽器開啟 `http://localhost:8501`
2. **選擇框架** → CDDA Framework (推薦)
3. **選擇受試者** → 例如 sub_0005
4. **配置設定** → 關閉 LLM 模式（快速測試）
5. **開始分析** → 點擊 🚀 開始分析
6. **查看結果** → 診斷報告、推理鏈、互動式檢視器
