## 📊 系統功能概覽

### CDDA Framework（核心創新）
- **雙 LLM 架構**: Agent A（決策）+ Agent B（臨床合成）
- **三路決策邏輯**:
  - 高不確定性 → 反事實模擬
  - 異常檢測 → 知識圖譜查詢
  - 標準情況 → 基礎報告
- **MCP 協議**: 資源與工具的清晰分離
- **完整推理鏈**: 所有決策過程透明可追溯

### 核心能力
1. **自主診斷**: 根據數據特徵自動決定分析策略
2. **不確定性量化**: SHAP + UQ + Z-score 多維度評估
3. **反事實分析**: What-if 模擬識別關鍵驅動因素
4. **混合病理檢測**: 識別潛在的多重疾病表現
5. **知識增強**: 360 個關係的腦區知識圖譜
6. **強健降級**: 多層級錯誤處理確保穩定性

## 🎯 系統架構

```
受試者 fMRI 數據
    ↓
Tool 1: 診斷報告生成
    ↓
Agent A 評估信號
    ├─ UQ > 0.8? ──→ Tool 2: 反事實模擬
    ├─ 異常檢測? ──→ Tool 4: 知識圖譜查詢
    └─ 標準情況 ──→ 基礎報告
    ↓
編譯 ContextObject
    ↓
A2A 交接給 Agent B
    ↓
Agent B 臨床合成
    ↓
最終診斷報告
```
