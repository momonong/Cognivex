## 🐛 已知問題

### 輕微問題

1. **檔案搜尋**: 如果資料結構不標準，可能找不到檔案
   - **解決方案**: 手動調整 `app_cdda.py` 中的搜尋路徑

2. **繁體中文**: 某些模型可能不支援繁體中文輸出
   - **解決方案**: 使用規則模式或更換模型

3. **推理速度**: HuggingFace 本地推理較慢
   - **解決方案**: 使用較小的模型或規則模式

### 無影響

1. **Neo4j 連線**: 如果 Neo4j 未啟動，會自動使用 fallback
2. **Ollama 警告**: 可以忽略，系統會使用 HuggingFace
